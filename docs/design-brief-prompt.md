# 设计提示词 —— 交给设计师（可直接粘贴）

> 用途：把下面整段作为 prompt 交给「Claude 设计师 / v0 / UI 生成工具」，产出高保真视觉稿 + 一套设计 token。技术落地是 React Native (Expo)，所以既要好看，也要能在移动端实现。

---

## PROMPT 开始 ↓↓↓

你是一位擅长「情绪化、疗愈类」产品的高级移动端 UI/UX 设计师。请为一款名为 **"频率"（暂定）** 的 iOS/Android App 做完整视觉设计。

**产品是什么**：一个私人的「阴影工作 + 显化」个人成长陪伴 App。用户通常在**被情绪触动、或想让自己安定下来**的时刻打开它。核心不是记录数据，而是营造一个**安全、温柔、不催促、略带神圣感**的独处空间。灵感来自灵性教练 Katie Clarke 关于"阴影自我""频率""临在"的方法论。

**要传达的情绪**：被接住的安全感、平静、被温柔看见、一点点仪式感与希望。**绝对避免**：像效率工具/表单/CRUD、冷冰冰、说教、廉价灵性风（紫色渐变、水晶、俗气 emoji）。

**目标氛围关键词**：温暖、留白、呼吸感、柔光、手写般的亲切、克制的高级感。

### 视觉方向（首选，另附两个备选，任选其一并说明理由）
- **首选：暖沙 · 静谧（Warm Sand / Quiet）**
  - 背景：暖米白/沙色（约 `#F5F1E8`），非纯白；深夜/沉浸场景用深墨（约 `#1F1B2E`）。
  - 主文字：暖墨黑（约 `#2A2622`）；次要文字：柔灰（约 `#8A8378`）。
  - 强调色：一个温暖的赤陶/琥珀（约 `#C97B5A`）作为唯一主强调；点睛可用一抹静蓝（约 `#6E8B96`）表示"临在/呼吸"。
  - 质感：大圆角（16–24pt）、极轻柔的阴影、柔光渐变，不要硬边和高饱和。
- **备选 A：暮光 · 极光（Twilight）**——深靛到暮紫的柔和渐变，适合更沉浸、夜间使用的调性。
- **备选 B：晨雾 · 素静（Misty Minimal）**——冷调灰白 + 一抹鼠尾草绿，更"性冷淡"极简。

### 字体
- 标题/引导语：一款有温度的**衬线体**（如 Fraunces / Lora / Newsreader），字重适中，可用斜体做情绪重音。
- 正文/UI：**人文无衬线**（如 Inter / Nunito Sans），行距宽松（1.5–1.7）。
- 中文：标题用思源宋体/需雅宋一类衬线，正文用思源黑体/苹方，保证中英混排和谐。

### 设计系统（请一并产出 token）
- 色板（含语义色：背景/表层/主文字/次文字/强调/成功/危险，浅色 + 深色两套）。
- 字阶（Display / Title / Body / Caption 的字号、字重、行高）。
- 间距系统（4 的倍数，强调"大留白"）。
- 圆角、阴影/柔光层级。
- 组件：主按钮（柔和、非默认蓝）、次按钮、文本输入区（大而软）、卡片、Tab Bar（**线性图标，不要灰三角**，风格如 Lucide/Phosphor 细线）、进度指示（用点或呼吸感，别用生硬进度条）。
- 动效原则：缓入缓出、"呼吸"节奏、轻微视差；关键处有触感反馈（haptics）与柔和过渡，**不要弹跳、不要花哨**。

### 要设计的屏幕（高保真，浅色 + 深色）
1. **首页/今天**：不是历史列表，而是一个温柔的入口——一句当日引导语 + 一个大而柔的"陪自己坐一会儿"入口 + 下方低调的历史入口。
2. **阴影日记 · 五步流程**：一屏一步，一句引导语居中、大量留白、慢节奏；底部柔和的前进/后退；"接纳"步是**呼吸圆环 + 轻触说三次'没关系'**的仪式，不是计数按钮。
3. **教练对话**：温柔陪伴感，打字机式逐字浮现的回应；不要冰冷的聊天气泡列表；"分享给教练"的动作要柔和，隐私提示一次性、不打断。
4. **冥想播放**：**最沉浸**——深色/渐变背景、随呼吸缩放的圆环、当前引导语大字浮现、极简播放控制、可选背景音；完成时是柔和的收束（微光/一句肯定），不是弹窗。
5. **信念改写**：把"限制性信念 → 赋能信念"做成有**蜕变仪式感**的呈现；新信念是一张可收藏的"频率卡片"，可设为每日提醒。
6. **状态/我的**：温柔的自我状态可视化（如"力量感 1–10"用柔和的光晕而非柱状图）、已收藏的信念卡、设置。
7. **空态、加载、完成态、错误态**：都要有情绪温度的文案与画面，给出情绪出口与肯定。

### 交付物
- 上述 7 类屏幕的高保真稿（浅/深）。
- 一份设计 token（JSON 或表格：颜色/字阶/间距/圆角/阴影），便于在 React Native 落地。
- 关键动效说明（进入、切步、呼吸、完成）。
- 图标清单与风格。
- 无障碍：对比度达标、字号可放大、深色模式。

### 约束
- 目标平台 React Native (Expo)，设计需可在移动端实现（避免依赖复杂 Web 特效）。
- 移动优先，单手可用，触达区 ≥44pt。
- 中文为主、需支持中英混排。
